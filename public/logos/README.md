# Logos de BotPager

Biblioteca de logos para reutilizar en el proyecto. Los 68 archivos conservan sus nombres y contenido originales.

| Carpeta | Composición | Archivos |
| --- | --- | --- |
| `Horizontal/` | Logo horizontal | 24 |
| `Icon/` | Icono | 20 |
| `Vertical/` | Logo vertical | 24 |

Cada carpeta incluye los formatos `SVG/`, `PNG/`, `JPEG/` y `PDF/`.

Para encontrar las variantes disponibles, consultar los archivos de la carpeta y el formato correspondiente. Respetar las mayúsculas y los nombres exactos: algunos archivos de `Icon/` se llaman `BotPaget-icon…` en los originales.

En la web, las rutas comienzan por `/logos/` (sin `public`). Ejemplos:

- `/logos/Horizontal/SVG/BotPager-Horizontal-Color_BoxedSVG.svg`
- `/logos/Icon/PNG/BotPager-Icon-Color_BoxedPNG.png`
- `/logos/Vertical/SVG/BotPager-Vertical-Color_BoxedSVG.svg`

Preferir SVG para logos escalables en la interfaz; elegir PNG o JPEG cuando se necesite una imagen rasterizada y PDF para materiales imprimibles. Revisar visualmente la variante antes de usarla sobre un fondo claro u oscuro.
